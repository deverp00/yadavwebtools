Contact

Feedback, bug reports, and requests for new tools.

Have a suggestion, found a bug, or want a tool we don't have yet? Send a message — every one is read. Requests that get asked for repeatedly are the ones we build next.

Email

The most reliable way to reach us. Include the tool name and a short description of your issue or idea.

hello@yadavwebtools.com

Bug reports

If a tool gives a wrong result or behaves unexpectedly, tell us what you entered and what you expected. Screenshots help.

bugs@yadavwebtools.com
How long until I hear back?
Replies typically go out within a few days. If you're reporting a broken tool, we try to acknowledge within 24 hours.
Can I request a new tool?
Absolutely. Describe what you want it to do, and if possible give an example of a task you'd use it for. The most requested additions get built next.
Do you accept contributions?
The site is currently maintained by a single author, but thoughtful fixes and suggestions are welcome by email. If you spot a security issue, please mark the subject line as "security" so it's prioritised.
Is my data safe if I email you?
Yes. Messages go to a private inbox and are used only to reply. We don't add addresses to any list, and we never share or sell them. See the privacy policy for details.
Something else?
Send a general message to hello@yadavwebtools.com and it'll land with the right person.

Before you write

If a tool isn't working, first try a hard refresh (Ctrl + Shift + R on Windows, Cmd + Shift + R on Mac) to clear any cached version. If a browser extension is blocking scripts, the tool may not run until you disable it for this site. And if a specific file type isn't supported, it's usually because the browser itself can't decode it — let us know the type and we'll see what's possible.

For privacy or data questions, the short answer is: nothing leaves your device when you use the tools. The long answer lives in the privacy policy.
