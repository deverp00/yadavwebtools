About this tool

The Image Resizer uses the browser's native Canvas API to redraw your picture at the dimensions you choose, then re-encodes it in the format you select. Because the work happens entirely on your device, files stay private and processing is immediate — even for large images.

PNG keeps transparency and lossless quality but produces larger files. JPEG is smaller and universally supported but does not support transparency. WebP offers the best compression-to-quality ratio in modern browsers and also supports transparency. The quality slider only affects JPEG and WebP output; PNG ignores it.

Animated GIFs are flattened to their first frame since Canvas does not preserve animation. SVG files that reference external resources may not render correctly for the same reason. For best results, use PNG, JPEG, or WebP source files.
