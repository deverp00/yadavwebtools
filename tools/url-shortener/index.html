URL Shortener

Turn long links into clean, shareable URLs.

Paste any long URL to generate a short link instantly. Runs on our own private shortener — no third-party services, no ads, no tracking. Your links are stored briefly so they can redirect, and nothing else.

How it works

Your browser sends the long URL to our private Cloudflare Worker endpoint, which stores it against a random 7-character code and returns a short link. When anyone visits that short link, the Worker looks up the original URL and issues a 302 redirect.

Custom aliases let you pick your own code (3–30 characters, letters, numbers, hyphens, underscores). If someone already claimed the alias, you'll be asked to choose another. Everything is served over HTTPS, and no analytics or tracking are attached to redirects.
