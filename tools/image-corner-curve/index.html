How the corners are rounded — without touching the pixels

The tool loads your image into a canvas that is exactly the size of the original file — for example, a 4000 × 3000 photo stays 4000 × 3000 in the output. A rounded-rectangle path is drawn on the canvas, and the image is clipped to that path before being painted. The pixels inside the shape are copied 1-to-1 with no scaling and no interpolation.

When you choose PNG, the canvas is exported with the browser's native PNG encoder, which uses lossless DEFLATE compression. The result is a file that contains the exact same RGB values as the source, only with the corners cut away. This is why a small rounded-corner PNG can be a few hundred kilobytes for a simple graphic and several megabytes for a detailed photo — nothing is thrown away to shrink it.

WebP export uses the browser's WebP encoder in its best-quality mode, which is visually indistinguishable from lossless for photographic content and also preserves transparency. JPEG does not support transparency, so when you export JPEG the corner area is filled with the background color you choose. JPEG is always lossy — the quality slider controls how much is thrown away, but even at 100% some compression occurs. For archival or print work, use PNG.

Per-corner controls let you create pill shapes, speech-bubble tails, or stylistic two-corner designs. The radius is measured in output pixels, so what you see in the preview is scaled proportionally — a 60-pixel radius on a 1000-pixel image looks the same as a 240-pixel radius on a 4000-pixel image.
