How to choose a password

Length beats complexity. A 16-character password using all four character sets has more than 100 bits of entropy — far beyond what brute-force attacks can reach with current hardware. Adding a symbol or two to a short password does not help nearly as much as making it longer.

Every password here is drawn from the browser's cryptographic random number generator. Unlike Math.random(), this source is designed to be unpredictable and is safe for security-sensitive values.

When the "require at least one from each set" option is on, the generator guarantees coverage and then shuffles the result so the guaranteed characters are not at predictable positions. Use a different password for every account, and store them in a password manager.
