About QR codes and this generator

A QR code is a two-dimensional barcode that can store up to several thousand characters of text. This generator uses the open-source qr-code-styling library, which builds on the well-tested qrcode-generator encoder. Every code is generated locally with proper Reed-Solomon error correction — the same algorithm used by commercial QR software.

Outer margin adds clean padding on all four sides of the downloaded image, so the code never touches the edge of the canvas or a page when printed. Corner radius rounds the outer edge of the image itself. Both values are percentages of the final image size — the defaults are 5% margin and 3% corner radius, which give a card-like appearance.

The PNG download is lossless by definition. PNG uses DEFLATE compression, which is reversible, so the pixels you download are exactly the pixels that were drawn. At 8000 px, the file will be large (10–25 MB), but every single module will be rendered at native resolution — no upscaling, no blurring, no quality loss.

Higher error correction levels add more redundancy so the code can still be read when part of it is damaged, dirty, or covered by a logo. Level H (30%) is the right choice when you plan to place a logo in the center. Level L (7%) produces the least dense code, which is best for very small prints.
