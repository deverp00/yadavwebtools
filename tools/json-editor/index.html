About JSON editing

JSON (JavaScript Object Notation) is a text format for structured data. It supports six value types: strings, numbers, booleans (true or false), null, arrays (ordered lists in square brackets), and objects (key-value pairs in curly braces). The syntax is strict: keys must be double-quoted, no trailing commas, and no comments.

This editor validates as you type and reports the exact line and column of the first syntax error. Trailing commas, single quotes, and comments are the most common mistakes — all three are rejected by JSON parsers even though plain JavaScript accepts them.

The tree view renders nested structures as an interactive hierarchy. Click the arrow next to any object or array to collapse it. The search box highlights matching keys and values across the whole document, and the tab count shows how many matches were found.

The Stats tab counts keys, objects, arrays, strings, numbers, booleans, and nulls recursively, along with the maximum nesting depth and the byte size of the minified output. Useful for spotting unexpectedly large payloads before shipping them over a network.

Format pretty-prints with 2-space indentation. Minify strips all insignificant whitespace. Escape string converts the current JSON into a quoted JSON-string (useful for embedding JSON inside another JSON document), and Unescape reverses that operation. Everything stays local — nothing is uploaded.
