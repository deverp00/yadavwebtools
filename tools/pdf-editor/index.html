Original quality guaranteed. Reordering, rotating, and deleting pages does not re-encode the content streams. The exported PDF contains the same page objects as the source — same embedded fonts, same images, same vector data — only the page order, rotation, and selection change.

About this PDF editor

Every operation on this page happens entirely in your browser. The file never leaves your device, so it is safe for contracts, bank statements, medical records, and any other sensitive document. Thumbnails are rendered locally with Mozilla's pdf.js library, and the final PDF is rebuilt with pdf-lib — both are widely used open-source projects.

Reorder — drag a page onto another page to swap their positions, or use the arrow buttons on each card. The order shown in the grid is exactly the order in the exported PDF.

Rotate — each rotation turns a page 90 degrees clockwise. Use it to fix scanned pages that came in sideways or upside down. The rotation is applied as a standard PDF rotate operation, so text stays selectable and searchable in the output.

Delete — removes the page from the output entirely. The original file on disk is not modified. You can undo by clicking "Reset edits", which restores all pages in their original order.

Encrypted or password-protected PDFs cannot be opened by this tool. Very large PDFs (hundreds of pages) may take a few seconds to load as each page is rendered to a thumbnail — the process is throttled so the page stays responsive while loading.
