Quick Reference

How conversions work

Length, mass, and volume use fixed conversion factors relative to a base unit (metre, kilogram, litre). A value is first converted to the base unit, then to the target unit — so chained conversions never accumulate rounding error.

Temperature is handled separately because the scales have different zero points. Celsius and Fahrenheit are converted with the standard formulas, and Kelvin uses absolute zero offsets. Negative Kelvin is physically impossible, so the tool clamps the displayed value and shows an inline note if you enter one.

The quick-reference panel lists the most common conversions for the currently selected category, updated live from your input value. Handy when you need a few related figures at once.
