About this accessibility tool

Voice dictation is powered by the Web Speech API, which is supported in Chrome, Edge, and Safari. Firefox currently does not support speech recognition, but the rest of the page — text to speech, reading adjustments, and contrast modes — works in every modern browser. When voice input is unavailable, the mic button is disabled with a note explaining why.

Text-to-speech uses the SpeechSynthesis API and voices installed on your system. The list of available voices depends on your operating system; if you do not see a voice for a particular language, install it in your system settings. The reading speed slider adjusts the rate from slow (0.5×) to fast (2×).

Reading adjustments apply only to the text area and preview paragraph on this page — they do not modify other websites. To resize everything on your screen, use your browser's built-in zoom (Ctrl + or Cmd + on most platforms). This tool is designed for short-form adjustments like increasing letter spacing or line height, which many studies suggest help readers with dyslexia or low vision.

Contrast modes: high contrast boosts the difference between text and background for maximum clarity; soft mode lowers the contrast to reduce glare for readers who find pure black-on-white fatiguing; grayscale removes all colour so hue is no longer a variable. Each is a preference, not a requirement — try them and keep what works.
