How number bases work

Every number system uses a base (also called radix) to represent values. In base 10, we use digits 0–9, where each position is worth ten times the one on its right. In base 2, only 0 and 1 are used, and each position doubles. In base 16, digits 0–9 plus A–F represent values 0 through 15.

Converting from any base to decimal is a sum of each digit multiplied by the base raised to its position. Converting from decimal to another base repeatedly divides by the base and collects remainders, reading them from last to first. This tool performs both operations and shows the result in every common base at once.

Binary is grouped in nibbles (4 bits) and bytes (8 bits) so the structure is easy to read. A single hexadecimal digit represents exactly 4 bits, which is why hex is the preferred shorthand for binary data in programming and debugging.

Very large numbers are supported through JavaScript's BigInt type, so you can convert values beyond the usual 253 safe-integer limit. Negative values and fractions are not supported — use a dedicated fixed-point or floating-point converter for those.
