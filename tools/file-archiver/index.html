About ZIP compression

A ZIP archive bundles multiple files into a single container. Each file inside is compressed independently using DEFLATE — a lossless algorithm that finds repeated patterns in the data and stores references instead of duplicates. Text, code, and documents typically shrink to 30–70% of their original size. Already-compressed files (JPEG, MP4, MP3, PDF) barely shrink at all because they contain little redundancy, and setting a high compression level on them just wastes time.

The compression level controls the trade-off between speed and file size. Fast uses a lower-effort DEFLATE pass and finishes quickly. Balanced is the standard ZIP default and works well for mixed content. Maximum spends more CPU to shave off extra bytes — noticeable on text-heavy archives, negligible on media files. Store only skips compression entirely and is useful when you just want a container without any processing delay.

Password protection uses AES-256, the same encryption standard used by governments and financial institutions. The password never leaves your device — it is used locally to derive a key that encrypts the file contents inside the archive. Without the correct password the files are mathematically unrecoverable, so store it somewhere safe before you close the browser tab.

Large archives (hundreds of megabytes) may take several seconds and use a noticeable amount of memory. If you get an out-of-memory error, try splitting the set into smaller batches. Chrome, Firefox, Edge, and Safari all support this tool; the ZIP files it produces open in every standard unzip tool on Windows, macOS, Linux, iOS, and Android.
