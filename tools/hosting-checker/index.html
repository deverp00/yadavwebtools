How to read the results

A records map a domain to IPv4 addresses — the numeric locations where the website is served from. If you see multiple A records, the site is distributed across several servers (often a CDN like Cloudflare or CloudFront). AAAA records do the same thing for IPv6.

NS records list the authoritative name servers for the domain — the systems that answer "where does this domain point?" for the rest of the internet. The provider listed here is often your DNS host (Cloudflare, Route 53, Google Domains, Namecheap, etc.), which is not necessarily the same company as your web host.

MX records handle email delivery. If a domain has no MX records, it cannot receive email. Each record has a priority — lower numbers are preferred. TXT records store free-form data: SPF and DKIM records used to prove email authenticity, domain verification strings for Google Workspace and Microsoft 365, and various other metadata.

CNAME records alias one domain to another. They are common for CDNs and for hostnames that should point to the same place — for example, www.example.com may CNAME to example.com, or an app subdomain may CNAME to a provider's load balancer.

The server location panel shows the geolocation of each IP address, the ISP that owns it, and its autonomous system number (ASN). This is the physical location where the server actually sits — often not where the company is headquartered, and often not where you are. CDN-hosted sites may show servers that respond from many regions around the world.
