How it works

A QR code stores data as a grid of black and white modules. The decoder reads that grid, corrects for rotation, perspective and minor damage using the code's built-in error-correction data, and reassembles the original text — typically a URL, plain text, contact card, or Wi-Fi credentials.

Image scanning draws the uploaded picture onto an off-screen canvas and reads its pixels locally. Camera scanning requests webcam access only after you click "Start camera", reads frames through the same canvas path, and stops the camera automatically as soon as a code is detected.
