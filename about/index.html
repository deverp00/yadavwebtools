About Yadav Web Tools

Free, private, browser-based utilities — no accounts, no uploads, no tracking.

Yadav Web Tools is a growing collection of free, client-side utilities designed to help you complete everyday tasks quickly and efficiently. Every tool runs entirely in your browser — no data is ever sent to a server, so your information stays private and secure by default.

What you'll find here

A single place for the small calculations and file operations that come up every day. Age and date math, loan and SIP projections, GST and percentage splits, image resizing and corner rounding, PDF merging and page reordering, ZIP archiving, currency and unit conversion, JSON editing, password and QR generation, accessibility helpers, and more. If it can be done in the browser, it belongs here.

Why it works this way

Most online tools upload your files or data to a server you don't control. We think that's unnecessary for most tasks and it creates real privacy risk. This site is built on the opposite principle: every calculation, every image transformation, every PDF operation happens on your own device using standard browser APIs. Close the tab and nothing is left behind.

How it's built

The site is written in plain HTML, CSS, and JavaScript. No build step, no framework, no tracker scripts, and no analytics. Third-party libraries are only included when a task genuinely can't be done with native browser features — for example, pdf-lib for PDF manipulation, JSZip for ZIP archiving, and TradingView for live forex charts. Each of those runs entirely client-side.

Keeping it fast

Pages load only what they need. Shared styles and scripts are cached by your browser after the first visit, so navigating between tools is instant. Dark mode and mobile layouts are handled by CSS variables and a single global stylesheet, keeping the codebase small and the experience consistent across every page.

Feedback and improvements

Suggestions, bug reports, and requests for new tools are genuinely welcome. If a calculation looks off, a file type isn't supported, or you'd like a feature added, use the contact page. Every message is read, and the most requested additions get built next.

Thank you

Thank you for using Yadav Web Tools. The goal is simple: useful tools that respect your time, your device, and your privacy — nothing more, nothing less.
